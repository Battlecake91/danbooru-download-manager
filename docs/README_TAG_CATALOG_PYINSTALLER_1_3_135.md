# 1.3.135 - Tag Catalog Pyinstaller

## Summary

Adds the local Danbooru tag catalog, first-run setup improvements, the default preview sample post, and executable build/runtime path hardening.

## Scope

**Area:** Tag management

- Tags are stored locally for search, scoring, aliases, and autocomplete.
- Typed tags distinguish artist, character, copyright, general, and meta information.
- Context actions avoid unnecessary full-table reloads where possible.

## Release context

This note is part of the accumulated development documentation for Danbooru Download Manager. The first public release is version `1.3.135`, after roughly 150 patches.
