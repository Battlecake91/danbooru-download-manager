# Viewer Tag Context Menu English Cleanup (1.3.140)

This patch removes the remaining German labels from the viewer tag context menu and related tag action dialogs.

## Changed

- `Scoring / Nutzung` is now `Scoring / usage`.
- `LLM-Eingabe ignorieren` is now `Ignore LLM input`.
- `LLM-Eingabe wieder nutzen` is now `Use LLM input again`.
- `Alias bearbeiten` is now `Edit alias`.
- `Tag(s) kopieren` is now `Copy tag(s)`.
- `Als Query in Zwischenablage` is now `Copy as query`.
- `Als Query in Preview suchen` is now `Search as query in preview`.
- The tag action error dialog title is now English.

## Notes

Only user-visible viewer tag action strings were changed. No behavior or database schema changed.
