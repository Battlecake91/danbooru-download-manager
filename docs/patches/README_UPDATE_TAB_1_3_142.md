# Update Tab 1.3.142

The portable GitHub release update check was moved from the top Help menu into a dedicated **Updates / Help** tab.

## Why

The update workflow is a core application function and should be visible as part of the main workflow instead of hiding behind a menu entry. The tab also gives the project a place for future built-in help and onboarding notes.

## Current contents

- Installed application version
- Button to check GitHub Releases for updates
- Portable updater explanation
- Placeholder note that more built-in help will follow

The updater remains active only in packaged builds. Running from source will not overwrite the working checkout.
