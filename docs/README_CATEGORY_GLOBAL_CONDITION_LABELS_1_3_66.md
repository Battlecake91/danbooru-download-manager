# 1.3.66 - Globale-Bedingung-Beschriftung vereinheitlicht

Kleiner UI-Fix im Kategorie-Tab.

## Änderung

- Die automatisch erzeugten Zeilennamen der globalen Regeln heißen nun nicht mehr `Immer 1`, `Immer 2` usw.
- Stattdessen werden sie als `Globale Bedingung 1`, `Globale Bedingung 2` usw. angezeigt.

## Unverändert

- Datenbankschema unverändert.
- Kategorie-Logik unverändert.
- `Globale Bedingung` bleibt als UI-Begriff erhalten.
- `Include-Regel` bleibt als Bezeichnung der Include-Regeln erhalten.
