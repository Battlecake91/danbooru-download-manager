# 1_3_51 Kategorie-Tab: Begriffe und Button-Layout

Geändert:

- Begriff `Treffer-Gruppe` wurde durch `ODER-Gruppe` ersetzt.
- Die Hinweise erklären nun klarer:
  - mehrere ODER-Gruppen sind Alternativen
  - Tags innerhalb einer Zeile sind UND-verknüpft
  - Tags mit `-` sind Ausschlüsse
  - globale Bedingungen gelten zusätzlich für jede ODER-Gruppe
- Kategorie-Aktionen wurden links unter die Reihenfolge-Buttons verschoben:
  - `↑ Kategorie hoch`
  - `↓ Kategorie runter`
  - `Kategorie hinzufügen`
  - `Kategorie speichern`
  - `Kategorie löschen`

Die Datenbankstruktur wurde nicht geändert.
